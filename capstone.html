University Capstone Project · In Progress

AI-Powered Marketplace Recommendation System

A pilot AI service for personalised product discovery, seller price guidance, and explanations grounded in model evidence.

Role
AI/ML Engineer
Status
Recommender developed; pricing component in progress
Pilot scale
100,000+ marketplace rows
Core business value

Helps buyers find relevant products and gives sellers evidence-based price guidance, making marketplace decisions clearer on both sides.

01 · The challenge

Better discovery and pricing decisions

Buyers can struggle to find relevant items in a large catalogue, while sellers may lack clear pricing benchmarks. The AI layer turns marketplace data into:

  • Listings matched to buyer interests and search intent.
  • Price guidance supported by comparable listings.
  • Short explanations of why each result was produced.

02 · My ownership

The AI/ML layer

I own the machine learning components, then coordinate their data and API integration with the wider team and whole marketplace.

  • Personalised and cold-start recommendations
  • Seller pricing experiments and evaluation
  • Reusable feature and model pipelines
  • FastAPI serving endpoints
  • Grounded LLM explanations
  • Data and application-team integration

03 · What it does

Four practical AI capabilities

Personalisation

Ranks listings using user history, content, location, and price preferences.

Cold-start handling

Uses popular listings when consent or interaction history is unavailable.

Price guidance

Combines comparable listings with a listing-specific model estimate.

Grounded explanations

Explains model evidence without letting the LLM invent recommendations.

04 · Buyer recommender

Relevant results for known and new users

For consenting users with enough history, the system builds a preference profile from viewed listings and ranks candidates by similarity. New or non-consenting users receive globally popular listings instead.

Each API response includes the recommendation type, ranked listings, and a short explanation.

05 · Seller pricing

Evidence-based guidance In progress

The pricing component is being designed to combine comparable listings, a listing-specific estimate, and the factors that influenced that estimate.

  • Group relevant comparable listings.
  • Estimate a price and typical range.
  • Explain only evidence produced by the model.

06 · Search + explanation

Personal relevance, clearly explained

The marketplace search component retrieves candidates from a text or image query. My recommender re-ranks those candidates using the user's preference profile. I do not own the complete semantic-search system.

Gemini then turns structured model evidence into plain-language explanations. It explains the result; it does not choose the product or price.

Search relevance Matches the current query.

Personal relevance Matches previous interests.
